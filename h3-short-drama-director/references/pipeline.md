# 全流程细则：锁 · 阶段门 · 拆段 · 红果规格

> 本文件是 `h3-short-drama-director` 的流程权威。SKILL.md 只给骨架，这里给判据。

---

## 一、G0 六项锁（详细判据）

### A 模式锁

| 条件 | 选 |
|---|---|
| 没有任何资产图，纯文字 | **T2VA**（零图，三字段） |
| 只有每段首帧图 | **I2VA**（指令行 + 三字段） |
| 只有收势定格图 | **L2VA**（指令行 + 三字段） |
| 首帧 + 尾帧都有 | **FL2VA**（指令行 + 三字段） |
| 有角色 3View / 场景 / 道具参考图 | **Ref2VA**（六段式） |

**短剧默认 Ref2VA**：因为短剧的核心成本在"人物一致性"，而一致性只能靠参考图锁。

关键判断：**三种模式不要混投**。同一集里若有的段有图、有的段没图，**统一降级成有图的那种模式**（缺图的段补一句文字外观），否则跨段人物会跳。

### B 画幅（不是锁，是恒定值）

**恒 9:16**，不提供其它选项，也不用 `auto` / `adaptive`。

- 不讨论"横屏更有电影感"——本项目只做竖屏。
- 不用 `auto`：auto 会在段与段之间改画幅，段缝直接崩。
- 载荷 `aspect_ratio` 一律写 `"9:16"`。
- 机检 H14 会拦：出现其它比例 → FAIL；全文未声明 → WARN。

### C 时长档

| 档 | 适用 |
|---|---|
| 4s | 单一反应、插入镜、细节特写（如"手机屏幕亮起"） |
| 5s | 短对白一来一回 |
| 8s | 标准叙事段（2–4 镜） |
| 10–12s | 有起承的完整节拍（3–6 镜） |
| 15s | 情绪完整段（5–8 镜），**上限** |

**拆段原则**：按**情绪节拍**切，不按字数切。一个"节拍"= 一次情绪变化或一次信息揭示。同一节拍不要横跨两段；一个段内不要塞两个反转（H3 15 秒塞两个反转会两头都不成立）。

### D 画风基底锁（决定机位规则）

| 基底 | 机位硬约束 |
|---|---|
| **BASE_LIVE** 真人 | 「脸部特写 × 平视正面」≤ 脸部特写总数 1/3 |
| **BASE_ANIME** 3D / 半写实 | **该组合默认禁用** → 必须带角度（侧45°/侧面/微俯微仰）；唯一豁免：正面对峙/摊牌且镜行写明理由 |
| **BASE_2D** 手绘 | 可用，同场连用 ≤2 次 |
| **BASE_INK** 水墨 | 同 2D，脸部特写本就不是主力景别 |

**未锁定基底就动手 = 违规。** 因为 3D 的正面平视脸特写会出"无纵深、塑料感、恐怖谷"，这是最容易被用户打回的崩点。

### E 资产形态锁

- **M1（默认）**：只有图号 + 生图提示词 + 《素材接线单》，不持有图。**不因缺图阻断下游**。
- **M2**：用户已出图并回传，按图锁形象，参考图进 9 图预算。

### F 段缝锁（跨段怎么接）

| 方案 | 用法 |
|---|---|
| **尾帧锚定** | 情绪顶点收段、下一段要延续同一动作/同一空间 |
| **换机位硬切** | 段间爆点、时间跳跃、场景切换 |
| **空镜过渡** | 文戏慢段、情绪下沉、时间流逝 |

硬规则：接缝两侧**强制换机位或换景别**（禁同机位硬接）；下一段首镜从上一段**真实末帧**起手；跨段连续剧情要配段缝分镜参考图锁末态。

## 二、阶段门判据

### G1 剧本门

- [ ] 每场有明确**冲突目标**（谁要什么、谁挡着）
- [ ] 每段（≤15s）有**一个钩子**：信息揭示 / 情绪反转 / 危险逼近
- [ ] 台词可演：每句能配一个可见动作或表情，不靠旁白解释
- [ ] 情绪节拍曲线已画：标注类型（紧张上升/爆发/留白/凝固）、强度 1–10、持续几镜
- [ ] 已标出**段切点**，并说明每段的功能（钩子/递进/反转/收束）

### G2 资产门

- [ ] 三清单齐全：角色外观 / 场景 / 关键道具
- [ ] 每个 `<Subject N>` 都有**图**或**文字档**（二选一，不许空）
- [ ] 9 图预算表已排，未超限
- [ ] 每张参考图都写了**用途**（锁形象 / 锁空间 / 锁道具 / 锁构图）
- [ ] 无"定义了却不引用"的 Subject

### G3 分镜门

- [ ] 无连续两镜"同景别 + 同机位"
- [ ] 无连续三镜同一运镜、无连续三镜全平视正面
- [ ] 机位配比：常规 ≤30%、侧45° 30–40%、侧面 ≤15%
- [ ] 每段开头有**正向越轴不变式**
- [ ] 每个摆了位的人在至少一镜出现，或写明出画
- [ ] 推拉镜都带 `10–15 cm` 物理限位
- [ ] 3D 基底下无"特写×正面平视"

### G4 编译门

- [ ] 字段集与顺序正确
- [ ] 指令行（如需）在第一行，后跟空行
- [ ] 正文全英文，`<d>` 台词保原文
- [ ] 声音三层已分开：环境音 / BGM / 对白
- [ ] `retention_analysis` 无 `(Sx)`
- [ ] **五遍词根清洗已过**（否定 → 元描述 → 抽象 → 心理 → 比喻程度）

### G5 机检门

1. **人工**：把稿子当"陌生人能不能照着画出来"读一遍——画不出来的句子都是污染。
2. **机检**：`python scripts/h3_lint.py <稿文件> --duration <秒>`
3. **判定**：FAIL（含 H13 词根、H14 画幅）必须清零；WARN 逐条说明或修正。

## 三、两层规格：剧本层沿用，生成层不套平台规则

**关键区分**：平台（红果 / 抖音付费）的那套规格是**发行侧**的东西，管的是"观众怎么被留住"。**H3 是生成侧**，它只认一个数——4–15 秒。

| 层 | 受什么约束 | 说明 |
|---|---|---|
| **剧本层**（① 剧本） | **可以沿用平台节奏逻辑** | 集长、钩子密度、台词长度、人物出场这些"讲故事的手艺"是相通的，直接沿用 |
| **生成层**（③ 分镜 → ④ 编译） | **只受 H3 规格约束** | 4–15s、图 ≤9、正文英文、词根清洗。**不因为"平台要求 60 秒一集"去凑时长或改段落结构** |

### 3.1 剧本层可沿用的东西（相通的）

| 项 | 参考值 | 为什么相通 |
|---|---|---|
| 集长 | 60–90 秒（付费点前） | 影响本集要讲几件事，与模型无关 |
| 钩子密度 | 每段末有钩子；每 15–20 秒一个强钩子 | 是叙事节奏，不是技术参数 |
| 首段 | 3 秒内出事，不铺垫 | 观众耐心，与模型无关 |
| 台词 | 短句为主，单句 ≤15 字，禁大段解释 | 表演可执行性 |
| 人物 | 主角首次出场正脸或侧脸清晰入画 | 认人需求 |
| 付费卡点 | 落在"信息揭示一半" | 剧本结构技巧 |

### 3.2 生成层不套用的东西（会被 H3 打乱）

- ❌ **"一集必须有 6–12 段"**：段数由**情绪节拍**定，不由平台集长倒推。有的 90 秒集拆 5 段就够，有的要 11 段。
- ❌ **"每段必须卡在某个秒数"**：H3 只有 4–15 的档，8 秒和 12 秒是**叙事选择**，不是平台指标。
- ❌ **"为了凑满 XX 秒加内容"**：注水会让 H3 自己加动作，反而崩。
- ❌ **"平台审核口径"**：H3 官方只有通用内容审核（违法/色情/侵权），**没有真人脸红线**，不要照搬其他模型的素材限制。

### 3.3 生成层的真硬规格（只有这几条）

| 项 | 值 |
|---|---|
| 画幅 | **恒 9:16**（不提供其它选项，不用 auto） |
| 单段时长 | **4–15 秒** |
| 参考图 | ≤9 张 |
| 参考视频 | ≤3 段（每段 2–15s、总 ≤15s） |
| 参考音频 | ≤3 段（必须与图或视频同用） |
| 混合总数 | ≤12 个文件 |
| 单段镜数 | 4s→1–2；8s→2–4；12s→3–6；15s→5–8 |

**首段特殊规则**（这条是叙事 + 生成双重理由）：`[Shot 1]` 必须有一个具名主体。**开场不许空镜**——空镜开场 H3 会给一个没人的空间。要么人先入画，要么用"人的局部"（她的手推开门）开场，并写清归属。

## 四、拆段实操

### 拆段信号（出现任一就切）
1. 情绪翻面（忍 → 爆发、稳 → 崩）
2. 信息揭示（观众刚知道一件事）
3. 空间切换（换房间/换场地）
4. 时间跳跃（过夜/一小时后）
5. 说话人换人（尤其同性别——见多说话人风险）

### 拆段禁区
- ❌ 一个段里塞两个反转
- ❌ 跨场景硬塞同一段演"连续走位"（双场景穿梭是穿帮高发源，改用蒙太奇直切）
- ❌ 为凑时长把一个 5s 的戏写到 15s（注水会让 H3 自己加动作，反而崩）
- ❌ 把一个大动作拆在段缝上（除非用尾帧锚定）

### 跨段连续的三件套
1. **末帧写清**：该段末镜句尾写「谁 + 在哪 + 姿态 + 道具状态」，能画出一帧
2. **首段重申**：下一段 `[Shot 1]` 重述同一状态（H3 零记忆，不重复就丢）
3. **机位错开**：接缝两侧换机位或换景别

## 五、一集的标准产出顺序

```
1. 分集卡（这一集要完成什么、卡点在哪个段）
2. 场次表（场次 / 地点 / 人物 / 冲突目标）
3. 台词稿（含语气位、开口密度）
4. 情绪节拍曲线（强度 1-10 + 持续镜数）
5. 拆段表（段号 / 时长 / 功能 / 段缝方案）
6. 三清单 + 9 图预算
7. 逐段镜行表
8. 逐段 H3 投喂稿
9. 机检 + 载荷
```

**不要跳步**。特别是第 4 步——节拍曲线是后面运镜速度、手持烈度、留白镜头的唯一依据，跳过就只能凭感觉，运镜必然平。

## 六、常见返工原因（提前避开）

| 现象 | 真实原因 | 修法 |
|---|---|---|
| 人物每段长得不一样 | 没用参考图锁 / 参考图用途没写 | 上 Ref2VA + 角色 3View，正文提一次 Subject |
| 配角莫名消失 | 该镜没点名在场者 | 每镜写全在场人 |
| 同一个人出现两个 | 只写名字没写位置 / 景别框不住却要求反应 | 单实例 + 位置锚点 + 拆反应镜 |
| 越切越乱、人物左右互换 | 写了"禁越轴"但没给正向不变式 | 每段首句写"摄影机在同一侧、A左B右" |
| 推镜把人脸推变形 | 没给物理限位 | `camera sliding forward 12 cm over three seconds on a rail` |
| 结尾莫名叠化融脸 | 用了中文"镜头切至" | 换 `the camera cuts to` |
| 角色说话时嘴不动 / 画外声却张嘴 | 画外声没用官方公式 | `says in an off-screen voiceover` + 闭口证据 |
| 两个人声音互串 | 同性别多说话人 | 拆段，一段一个开口者 |
