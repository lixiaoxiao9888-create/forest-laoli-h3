# H3 分镜三件套：运镜 · 越轴 · 站位

> ★ 本文件是 `forest-laoli-h3` 的核心。H3 的崩坏 80% 集中在这三件事上。
> 原则：**机制照搬成熟短剧分镜（7.4.20 基线），表达换成 H3 吃得下的"画面事实"。**

---

## 零、先记住一句话

**导演稿里怎么想都行（坐标、轴线、编号、分级），投喂词里只留看得见的事实。**

H3 不是在"理解导演意图"，是在"按文字渲染画面"。你写"轴线锁定"，它渲染一个锁；你写"禁止越轴"，它渲染一个轴。**只有名词和动作会被画出来。**

---

## 一、运镜与机位（速查 · **运镜权威见 `camera-movement.md`**）

> 本节只留最常用的判据。**运镜的完整规则在 `camera-movement.md`**：22 种运镜的 H3 可执行度、幅度厘米刻度、运镜×景别矩阵、画幅差异（9:16 竖屏 / 16:9 横屏）、节奏衔接、复合运镜、八档档位、15 条病根台账、12 条句型模板。

### 1.1 镜行只写三要素

```
[Shot N] <景别>, <机位角度>, <运镜>; <画面事实>.
```

例：
```
[Shot 2] Medium close-up, 45-degree side angle, the camera slides forward 12 cm over three seconds on a rail; she turns her head toward the window, lips pressed thin.
```

- 景别 / 机位角度 / 运镜——**只这三样**，多余的形容词删掉
- 三要素之后**用分号**，后面只写人物与道具的纯物理动作
- 五要素（含焦段、景深、光影）是**设计时**的检查表，落稿砍到三要素

### 1.2 三条硬底线

**① 推拉必须带「距离 + 时长 + 轨道」三件**
```
❌ slow push in
✅ the camera slides forward 12 cm over three seconds on a rail
```
H3 不知道"慢"是多慢，没距离就推猛，没时长就变抖，没 `on a rail` 就带手持晃动。

**② 每镜必须写运镜，静止也要写**
不写 → H3 自由发挥：自加建立镜头、自加摇镜、或全程死静。静止写 `the camera holds still`。

**③ 画幅取向决定位移方向（推荐 9:16 / 可用 16:9）**
- **9:16 竖屏**：横向是短板，横移超过 20cm 就出画；"展开空间"靠**上下竖移**和**前后景叠压**，不靠左右横移。
- **16:9 横屏**：纵向是短板，竖移幅度按竖屏的 0.6 倍收；横移宽裕（上限可放到 40cm），双人可并排不用前后错位。
- 无论哪档：**全片只用一个画幅**，段间不换。

### 1.3 禁用与替代（写进去就废镜）

| 禁用 | H3 的行为 | 替代 |
|---|---|---|
| 升格 / 慢动作 / slow motion | 当静帧，或直接忽略 | 删；强调靠特写 + 更细的动作 |
| Hit-Stop / 顿挫 / 定格 | 没有帧级时间控制 | 写受力结果：`his head snaps back` |
| 急速变焦 / 甩镜 | 0.2s 精度做不出 | `the camera cuts to ...` + 时间戳 |
| 滑动变焦（Dolly Zoom） | 位移 + 反向变焦双重控制，做不稳 | 拉远 + 焦点转移 |
| 摇臂 / Snorricam | 多向复合、主体锁定 | 拆两个 `[Shot]`；或 `hand-held, the frame tilts` |
| 手持剧烈晃动（持续） | 全片糊 | 单次冲击：`the frame jolts once` |

### 1.4 幅度硬上限（超了必崩）

| 景别 | 推拉 | 横移 | 摇/俯仰 |
|---|---|---|---|
| 特写 / 大特写 | **10 cm** | **禁** | 5° |
| 近景 | 15 cm | 10 cm | 10° |
| 中近景 | 20 cm | 20 cm | 15° |
| 中景 | 40 cm | 50 cm | 25° |
| 全景 | 80 cm | 1.2 m | 40° |
| 远景 | 1.5 m+ | 2 m | 60° |

### 1.5 运镜速度 = 情绪强度（详见 `camera-movement.md §三`）

| 情绪 | 速度 | 换算 | 典型 |
|---|---|---|---|
| 平静 1–3 | 极慢 | <5 cm/s | 微推 / 微横移 / 几乎静止 |
| 紧张 4–6 | 慢–中 | 5–12 cm/s | 缓推 / 跟拍 / 手持微晃 |
| 爆发 7–9 | 快 | 20–60 cm/s | 快推 / 快横移 / 手持 |
| 留白 | 静止–极慢 | <3 cm/s | 固定 / 极慢拉 |
| 凝固 10 | 静止 | 0 | 固定大特写 |

**反规则**（每段 ≤1 个机会点）：绝望 → 反而拉远；震撼 → 反而固定大特写；暴力瞬间 → 反而切空镜/拉远；阴险反派 → 反而平视贴近；失败者的尊严 → 反而平视。

### 1.6 运镜节奏（H3 逐镜渲染，这条比 Seedance 更重要）

| 衔接 | 合法性 |
|---|---|
| 动 → 动 | ✅ 但要换方向或换速度 |
| 动 → 静 | ✅✅ 天然句号，收段最好用 |
| 静 → 动 | ⚠️ **必须有触发**（门响/起身/一句台词） |
| 静 → 静 | ✅ 对话段正反打靠这个；连续 ≥3 镜全静则死 |

**H3 没有镜头间的运动惯性**：上一镜快速横移、下一镜立刻固定 → 出片是"急刹车"。**快镜后面跟慢镜做缓冲。**

### 1.7 留白镜（重锤后必加）

- 环境空镜 / 无台词反应镜 / 动作细节空镜 / 固定长镜，**景别比爆发镜更松**
- **不许连续两个重锤**
- **H3 侧铁律**：留白镜**不要写成纯空镜**——H3 会给一个没有人的房间。写**人的局部**：
```
❌ the empty room, rain on the window
✅ her hand on the door frame, still, rain on the window behind it
```

### 1.8 多样性（H3 缩水版）

- 禁**连续 2 镜**同一运镜（对话段 `holds still` 豁免）
- 一段 ≥2 种运镜；一集累计 ≥5 种
- 物理条件不足**不硬凑**；禁为多样性加无叙事理由的运镜

---

> 机位是运镜的落点。**不写机位角度，H3 默认正面平视**——3D 基底下这是恐怖谷最快的一条路。

### 1.9 方向轴 × 高度轴

**方向轴**

| 角度 | 情绪 | 适用 |
|---|---|---|
| 正面 | 直接、坦荡、对抗 | 对峙 / 坦白 / 摊牌 |
| **侧45度** | 张力与交流并存、立体 | **对话叙事默认机位** |
| 侧面90° | 隔绝、疏离、心门关闭 | 回避 / 诀别 / 独白（≤15%） |
| 过肩 | 建立空间关系 | 双人对话 / 对峙 |
| POV | 沉浸代入 | 角色视角 / 恐惧 / 发现 |

**高度轴**

| 角度 | 情绪 |
|---|---|
| 平视 | 中性、平等 |
| 微仰/微俯 ≤15° | 隐性强弱暗示（常规叙事调味） |
| 仰拍 15–45° | 力量、威严、压迫 |
| 俯拍 15–45° | 弱小、孤独、无助 |
| 大仰角 >45° | 压倒性力量、巨物感、恐惧源 |
| 大俯角 >45° | 被世界碾过、彻底绝望 |
| 鸟瞰 | 全知、宿命、渺小 |
| 荷兰角 | 世界失衡、认知崩塌（每集 ≤1 镜） |

### 1.10 机位配比铁律

- **常规镜头 ≤30%**（平视 + 正面/纯过肩 + 平稳运镜）——它是呼吸和基准线，压到三成是为了让激进机位有落差
- **侧45度 30–40%**——短剧视感主力
- **侧面90° ≤15%**——只给心门关闭的时刻，且侧脸**必须有有源的轮廓光**（窗/灯/火/霓虹），糊黑侧脸不合格
- 大仰/大俯各 ≤3 次/集，二者对切（仰拍强者→俯拍弱者）是权力碾压经典组合
- 连续 3 镜不得全部平视正面；同场 ≥4 种角度
- **9:16 竖屏特例**：全景装不下"仰拍的压迫感"→ 用**低机位仰拍中景**代替（16:9 横屏不受此限，可直接大仰拍全景）

**机位角度反规则**（每场找 1–2 个机会点）

| 常规 | 反着用 | 效果 |
|---|---|---|
| 反派 → 仰拍 | **平视或微仰贴近** | 近在咫尺的威胁比崇高的更阴险 |
| 受害者 → 俯拍 | **大仰角拍施暴者** | 代入受害者视角，压迫最大化 |
| 失败者 → 俯拍 | **平视** | 绝境里给他最后的体面 |
| 英雄 → 仰拍 | **俯拍脆弱瞬间** | 立体化，不是塑神 |
| 强者跌落 | **大俯角** | 从云端跌进尘埃 |

**物理可行性**（写之前先想机位放哪）

- 大仰角：贴地或腰部以下向上
- 大俯角：必须有真实高点（楼梯口/二层回廊/高柜顶/门框上沿/天桥）；普通层高无高点 → 降级 30–45° 俯拍；**禁凭空悬空机位**
- 侧面：人物侧向要有放置空间，贴墙改用侧45°
- 鸟瞰：镜头能到场景正上方 3m 以上
- 过肩：机位能退到人物背后 1.5–2m

### 1.11 过肩几何（最容易写反的一处）

写"过肩"必须同时写清：**摄影机在被越角色背后还是前侧、越过哪一侧肩**。

| 类型 | 摄影机 | 画面**左**前景 | 画面**右**前景 |
|---|---|---|---|
| 后肩·过右肩 | 角色背后 | 该角色右肩 | — |
| 后肩·过左肩 | 角色背后 | — | 该角色左肩 |
| 前肩·过右前肩 | 角色前侧、向其身后拍 | — | 该角色右前肩 |
| 前肩·过左前肩 | 角色前侧、向其身后拍 | 该角色左前肩 | — |

- 前肩只保留**肩部/侧颈/少量侧脸边缘**，完整正脸与躯干不入画
- 后方主体必须**真实露出**；两人前后完全重合 → **不得写"后方可见"**
- **三种左右不许混**：物理空间左右 / 画面构图左右 / 人物自身左右。换机位只改画面左右，**不改人物物理位置**
- **H3 写法**：`over-shoulder` 后面必须带 `his soft shoulder fills the near left of the frame` 这类**可见事实**，不能只写 `over-shoulder shot`

### 1.12 摄影几何四步（禁先写构图再倒推机位）

1. **读上镜结束状态**：站位、朝向、视线、道具在谁手里
2. **定位本镜摄影机**：同侧 / 过肩 / 反打
3. **判可见性**：从该机位实际能看到谁、看到多少身体、什么被挡
4. **只写第 3 步成立的内容**；要展示完整位移或多人关系 → 改用更宽的景别

- 反打由**新机位独立重建**前后景——上一镜的后景角色**不会**因为剪辑自动出现在反打里
- 不可见的人写"不入画"，**不得为说明"还在场"虚构后景**

### 1.13 形态→机位（★ 3D 必看）

| 基底 | 脸部特写角度 | 「特写×正面平视」配额 |
|---|---|---|
| BASE_LIVE 真人 | 可正面平视 | ≤ 脸部特写总数 1/3 |
| **BASE_ANIME 3D/半写实** | **必须带角度**（侧45/侧面/微俯微仰） | **0（默认禁用）**，除非正面对峙/摊牌且镜行写明理由 |
| BASE_2D 手绘 | 以风格化为准 | 可用，同场连用 ≤2 次 |
| BASE_INK 水墨 | 同 2D | 可用，同场连用 ≤2 次 |

**核心**：**三轴各自合规 ≠ 组合合规**。方向=正面（合法）+ 高度=平视（合法）+ 景别=特写（合法）三者叠加，在 3D 下就是"无纵深、塑料感、恐怖谷"。

### 1.14 H3 表达转换（照抄这张表）

| 成熟分镜原写法 | H3 改法 | 原因 |
|---|---|---|
| 跟随 `@某人` | 写相对位移：`the camera drifts with her at shoulder height` | H3 不认 `@` 锚点，`follow her` 还可能多出一个人 |
| 升格 / 慢动作 | **删掉** | 会被当静态帧或直接忽略 |
| 命中定格 / Hit-Stop | 写受力结果：`his head snaps back` | H3 无帧级时间控制 |
| 中文"镜头切至" | `the camera cuts to` / `the shot cuts to` | 中文不被绑定，会自由发挥成叠化融脸 |
| `85mm F1.4 极浅景深` 塞镜行 | 移到段首风格句 | 稀释人物动作权重 |
| `焦平面死锁面部 / 呼吸式微动 / 构图平整` | **不写** | 摄影机说明书会被当画面内容渲染 |
| 单镜内分阶段运镜（起幅晃→收尾稳） | **拆成两个 `[Shot N]`**，各自带运镜 | H3 单镜内不做多阶段摄影机演进 |
| "缓慢推进" | `sliding forward 12 cm over three seconds on a rail` | 没限位会推猛 |
| 滑动变焦（Dolly Zoom） | 拉远 + 焦点转移 | H3 做不稳位移+反向变焦 |
| 环绕 180° | 砍到 ≤90° | 转半圈会丢背景一致性 |
| 摇臂 / Snorricam | 拆两镜 / `hand-held, the frame tilts` | 多向复合、主体锁定做不到 |

### 1.15 H3 时长适配

- 单段 **4–15 秒**
- 15s 档 4–5 镜；12s 档 3–4 镜；8s 档 2–3 镜；4s 档 1 镜
- 首镜不带时间戳；后续 `[Shot N] At 00:04.000,` 严格递增
- 景别或角度**微变** → 用运镜，不切镜

## 二、越轴（H3 增益最大的一层）

### 2.1 机制

轴线 = 两人视线/动作的连线。**所有机位必须在轴线同一侧**，否则观众空间感崩（人物左右互换）。

### 2.2 三种合法越轴（必须有替代方案，不能只写"禁"）

| 手段 | 何时用 | H3 写法（不要写"越轴/过轴"） |
|---|---|---|
| **① 镜头内过轴** | 角色走位穿越轴线，镜头跟着绕 | `The camera arcs around them as she walks past him; the shot ends with her on the right, him on the left.` |
| **② 中立镜头过渡** | 需要切到轴线另一侧 | 先插一个 `[Shot] Frontal medium shot facing both of them, static.` 或 `Close-up of the cup on the table.`，**下一镜**才换侧：`The camera is now on the other side; he is on the left, she is on the right.` |
| **③ 受击/剧烈位移重建** | 打斗、被推倒、翻滚后位置变了 | `He is knocked back against the wall; now she stands on the left, he is on the right.` |

另外：**禁 90° 侧面正拍中景全景**（会丢透视纵深），中景全景必须斜角。

### 2.3 H3 写法：正向不变式

**为什么不能写"禁越轴"**：H3 对否定不敏感、对词根敏感。"不要越轴"里的"越轴"会被渲染成画面信息（观众看到一条轴/一条线）。

**每段开头写一次，后续镜默认继承**：
```
The camera stays on the same side of them throughout; she is on the left, he is on the right.
```

> ⚠️ **别写 `line` / `axis` / `frame`**。早期模板是 `on one side of the line between them` —— `line` 有被画成一条线的风险，`left of the frame` 里的 `frame` 也可能被画成画框。**直接写 `on the left` / `on the right`。**

- ❌ 绝不出现：轴线锁定 / 禁越轴 / 180度 / 左A右B / CAM2 / 不要反打 / line / axis / frame
- ✅ 导演稿内部照旧可用 `左A右B`、`CAM1~4`（给人看、给机检），**投喂前必须翻译**
- 侧面机位必须有光：`rim light from the window behind her`（否则侧脸糊黑，H3 特别明显）
- 更细的词根替换见 `h3-lexicon-cleanup.md`

### 2.4 移动轨迹闭环

角色移动必须 `起点 → 可见路径 → 终点`。上一镜在左，下一镜不能瞬移到右。写完每个走位问一句：**中间那一帧画得出来吗？**

## 三、站位

### 3.1 根因：图画在导演稿，字写在投喂词

"站位老大难"的真实根因是——**过去只写"禁止画图"，导致执行者没有调度手段，站位只能凭感觉。**

分两层：

| 层 | 允许 | 禁止 |
|---|---|---|
| **导演稿（内部）** | 文字平面图：场景坐标系（东南西北）+ 固定物 + 出入口 + 人物初始位与朝向 + 行动区 | ASCII 草图 / 画格示意 |
| **投喂词** | 一行式站位句：位置 + 依托物 + 朝向 + 姿态 + 位移 | **任何形式的图**：坐标表 / ASCII / 俯视图 / 2x2 网格 |

一句话：**图在导演稿里，字在投喂词里。**

### 3.2 三条硬规则

1. **绝对方位优先**：导演稿用"北/南/东/西 + 固定物"，不用"画面左/右"（画面左右随 机位变，物理方位不变）
2. **每步有依托**：站位必须挂一个固定物（门口/桌后/窗边/床边）——**悬空 = 漂移源**
3. **写一次，全段引**：位置只声明一次，后续镜不重复另一套方位说法（双重发位是"东一个西一个"的病根）

### 3.3 一行式四要素 + 位移

```
<人物> stands <依托物/位置>, facing <方向>, <姿态>; <位移：从A到B，因X>.
```

例：
```
[Shot 1] She stands a step behind the desk, half-turned toward the courtyard, hands clasped; he sits behind the desk, facing her.
```

### 3.4 空间风险分级 S0–S4（内部判断，不写进正文）

| 级 | 情形 | 需要什么 |
|---|---|---|
| **S0** | 单人 | 简版一行（位置+朝向+动作），免轴线免位移链 |
| **S1** | 双人静态 | 四要素 + 轴线不变式 |
| **S2** | 多人静态 3–4 人 | 全员具名四要素 + 轴线不变式 |
| **S3** | 多人移动 | S2 + 逐人位移因果链 |
| **S4** | 复杂战斗 / 多人多区切换 | 全量（顶视图调度 + 合法越轴 + 前三级全部） |

判定不清**按高一级处理**。短剧 80% 的戏落在 S1/S2——**别一上来就上 S4 那套，规则量翻三倍还没用**。

### 3.5 四个高频病根 → H3 侧写法

| 病根 | 真实原因 | H3 侧修法 |
|---|---|---|
| **丢人**（配角莫名消失） | 该镜只写了主角 | 每镜开头点名**全部在场者**：`She stands by the door; he sits at the desk; the old servant waits in the far corner.` 无"来人/离开"描述时默认全员原样在场 |
| **分身/复制人** | 地点悬空 + 只写名字不给位置 | ① 每个角色**只在一个位置**，且必须带依托物；② 已走位的人每镜带当前位置（`now at the door`），**禁悬空点名**；③ 位移写"迁移"不写"复制" |
| **乱位**（突然出现在身后） | 同一角色被给了两套方位 | 位置**只声明一次**；换机位只改画面左右，不改物理位置 |
| **景别不匹配** | 中近景点名远处的人做可见反应 | 中近景只点**相邻 1 人**；远处的人三条合法路：① 升全景同框 ② **拆反应镜**（主体镜写"其余人不入画" + 反应镜单独给全景） ③ 降为画外音。**"缓慢拉镜拉出全员"不算合法处理**（拉镜只是景别渐变，改不了物理距离，模型照样补人） |

**为什么"景别-取景半径"是分身根因**：镜头能框住谁，由**景别 × 站位物理距离**共同决定，不由台词需要决定。隔着半个厅的人被要求做可见反应，模型无法让他入画，只能**把他挪到主体身边渲染，或复制一个**。

### 3.6 群戏与权力几何

- **主焦点 1 人**：本镜的情绪主动作只给一个人
- **次反应 1–2 人**：幅度要小（转头、退半步、垂眼）
- **背景其余**：循环性动作（添茶、侍立、擦桌、翻账本）
- **禁全员抢动作**

权力几何用**可见空间差**写，不写抽象词：

| 关系 | 可见写法 |
|---|---|
| 上位 | 占中央 / 坐主位 / 站高处 / 身体完全展开 |
| 下位 | 退到门边 / 被桌沿遮去半身 / 跪坐 / 缩在角落 |
| 压迫 | 站到对方身后 / 影子盖住对方 / 逼近至半步内 |
| 隔断 | 中间隔一张桌 / 隔一道门 / 一人背对 |

### 3.7 跨段（H3 每段零记忆）

- **跨段切、同段连**：段与段是**剪辑关系**，不是连续拍摄关系。默认蒙太奇直切（前段终态 → 后段开场）
- **严禁把两个场景塞进同一段**演"连续走位"——双场景穿梭是穿帮高发源
- **同段内**位置断层才需要走位声明，且每步有动作原因
- **前段埋钩子**：后段要登场的人/物，前段尾拍提前入画（远景剪影、视线指向、声音预告），否则后段出场无来由

### 3.8 摆位必入画

站位里摆了位的每个人，**必须在至少一个镜出现**（正拍 / 焦外身影 / 全景群像 / 反应镜都算），否则写明"已出画 / 已退场"。H3 没有站位栏可查，这条只能由编译者守住——机检 H5 兜底。

## 四、一页速查（每段投喂前过一遍）

- [ ] 镜行 = `[Shot N] 景别, 机位角度, 运镜; 画面事实.`（三要素缺一即失控）
- [ ] 每个推拉都带**距离 + 时长 + 轨道**（`sliding forward 12 cm over three seconds on a rail`）
- [ ] 幅度没超景别上限（特写 10cm / 中景 40cm / 全景 80cm）
- [ ] 没有禁用运镜：升格 / Hit-Stop / 急速变焦 / 滑动变焦 / 摇臂 / Snorricam
- [ ] 位移与变焦没有同镜叠加
- [ ] 画幅对上了吗？**竖屏**：横移砍半，展开空间靠竖移与前后景叠压；**横屏**：横移可放到 40–60cm，竖移压 0.6 倍，双人可并排
- [ ] 无连续 2 镜同运镜；无连续 3 镜全平视正面
- [ ] 静止镜写了 `the camera holds still`（不写＝H3 自由发挥）
- [ ] 机位配比：常规 ≤30% / 侧45° 30–40% / 侧90° ≤15%
- [ ] 3D 基底：无「特写 × 正面平视」（除非写明对峙理由）
- [ ] 段首有正向越轴不变式；无"禁越轴/轴线锁定/180度"
- [ ] 每镜点名全部在场者；每个角色只在一个位置
- [ ] 走位过的人带当前位置
- [ ] 中近景没有点名远处的人做可见反应
- [ ] 摆了位的人都有镜头
- [ ] 切镜只用官方绑定短语；无中文"镜头切至"
- [ ] 无摄影机说明书、无坐标/ASCII/`@`/栏名
