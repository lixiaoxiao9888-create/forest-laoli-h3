# 资产层：三清单 → 参考图 → 9 图预算

> 目标：用**最少的图**锁住**最多的一致性**。H3 只认图，不认设定表。
>
> **出图工具不限**：本地 ComfyUI、在线生图服务、任何客户端自带的文生图都行（v2.0 起不再绑定某个具体工作流）。
> 下面的提示词模板与版式规则是工具无关的，**照着写就行**。缺图**不阻断下游**，降级为文字档。
>
> **一条取舍**：优先用**纯文生图**（可固定 seed、可复现）。带参考图槽的换装/改脸工作流反而容易把三视图的身份拽跑，
> 真正的锁脸在 H3 端做——三视图就是参考图槽，全片一直挂着（见 §二·补 与 §六）。

---

## 一、三清单（从剧本抽，不是从想象抽）

### 1.1 角色清单

每个角色一条，只写**可见**：

```
图3 = 沈砚（28岁男，短寸黑发，左眉尾一道旧疤，深灰立领中山装，右腕细银链，身高偏瘦）
```

**必填五项**：年龄段 / 发型发色 / 面部显著标记 / 服装（可换）/ 体型
**不要写**：性格、身世、职业感、气质形容、声音、表情习惯

> H3 会把"气质阴郁"渲染成一张阴沉脸，而不是"有故事的人"。**只写能被画出来的。**

### 1.2 场景清单

```
图1 = 宋府书房（一张主视角：正对空间，能同时看到书案区 / 窗边 / 书架 / 门口）
```

**必填**：空间类型 / 主要固定物（3–5 件）/ 光源位置与性质（窗光/灯光/火光）/ 出入口 / 时代锚（年代/地域风格）

**关键**：场景清单要能回答"人站哪"。如果写不出三个可站的位置，这个场景描述还不够。

### 1.3 道具清单

```
图7 = 绣花帕子（月白底，角上一朵褪色红梅，边缘磨毛，巴掌大，可握于掌心）
```

**必填**：材质 / 尺寸（相对人体的参照）/ 颜色纹理 / 状态（新/旧/破损/染血）/ 关键特征（要能被认出来的那一点）

**反光道具注意**：玉佩、银器、镜面类——生图提示词里写"哑光/本色"，**不写光斑、受光、亮起**，否则 H3 会给你一个发光物件。

## 二、生图提示词模板

### 2.1 角色 3View 资产板（1 张图 = 1 个角色）

**三格：正面全身 / 侧面全身 / 背面全身。**

> 不要再写四视图、不要加"面部特写"那一格。四格版会把整个人压得很小，
> 脸上细节反而糊；H3 从三格正中那张正面图里取脸就够了。

```
[主体] 28岁东亚男性，短寸黑发，左眉尾一道浅疤，瘦削，深灰立领中山装（棉麻质感，立领扣到顶），右腕细银链
[版式] 画面被两条竖线均分为恰好三格，从左到右依次排列：第一格正面全身、第二格侧面全身、第三格背面全身；三格同一人物、同一服装、同一光位、同一比例
[光线] 中性灰背景，均匀柔光
[风格] 写实电影质感，皮肤保留毛孔与细纹，不磨皮
[禁止] 画面里正好三格，不要两格，不要四格，不要文字，不要水印，不要多余人物，不要夸张表情
```

**要点（2026-10-21 真机验证过，措辞不能改）**
- **必须写「恰好三格」+「被两条竖线均分」+「从左到右依次是」+ 每格画什么**。只写"三格并置"实测只出两格（正面 + 背面，侧面被吃）
- **写「侧面全身」，不要写「左侧面全身」**。"左侧面"会被模型理解成"画面左侧的正面"，还是出正面
- 三格必须**同一光位**，否则出图后三格像三个人
- 画幅用 **4:3 横版、约 2.0 百万像素**（实测 1664×1216），**不要用成片画幅（尤其 9:16）**——竖版三格只能上中下叠，人会很窄
- 一个角色**只出一次**，出了就不再改。全片所有段都挂这一张（见 §六）
- **出来的图没有水印，不需要裁底**。老流程那道"裁底 8% 去水印"可以去掉

### 2.2 场景图（1 张图 = 1 个空间）

**只出一张，正对空间的单一平视主视角。不要九宫格，不要多视角拼图。**

> 这不是省事，是 H3 的能力边界（2026-10-21 定）。给它一张多视角拼图，它认不出哪个是"这个空间"，
> 会自己在正文里补空间——补出来的往往是 H28 那类尺度膨胀（一面墙变成照片展厅）。
> **一张干净的主视角，反而能把"墙上有几件东西、地上有什么"钉死。**

```
[主体] 民国书房，深色木质书案（案上有砚台、毛笔架、一叠信纸），身后顶天书架，右侧木格窗（窗外竹影），左侧屏风
[视角] 正对空间的一个平视主视角，能同时看到书案、书架、木格窗与屏风，四件都不出画
[光线] 右侧窗光为主光，色温 4500K，室内暗部保留细节
[风格] 写实，年代剧质感，木料有使用痕迹
[禁止] 不要文字、不要人物、不要现代物品、不要多格拼图、不要俯视图、不要多个视角
```

**要点**
- 固定物写 **3–5 件，全部单数**（H28：禁 `wall of` / `rows of` / `dzens of`）
- 必须"能同时看到"这几件——这是它跟空间锚点卡对上的唯一方式
- 画幅**跟成片同画幅**：竖屏项目出 `9:16`（约 2.0 百万像素，实测 1088×1856）；横屏项目出 `16:9`
- 一个空间**只出一张**。换景别不换图，靠正文的机位词去切

### 2.3 道具设定图

```
[主体] 月白色绣花帕子，棉质，边缘磨毛，角上一朵褪色红梅（丝线起球），展开约 20cm
[版式] 单件居中，微俯视，右下角一枚硬币作尺寸参照
[光线] 柔光，哑光呈现，无高光反射
[风格] 写实，旧物质感
[禁止] 不要文字、不要手、不要光效
```

## 二·补、出图工具怎么选（工具无关）

### 2.4 选工具的判据

不看牌子，看三条：

| 判据 | 为什么 |
|---|---|
| **纯文生图、能固定 seed** | 可复现。三视图出歪了能微调重来，不会每次换一个人 |
| **能出 2.0 百万像素以上** | H3 取脸靠的是三视图正中那张正面格，脸部像素不够会糊成平均脸 |
| **不出水印 / 不出黄图** | 有水印要裁底，裁多了脸就偏；出黄图整批返工 |

**换来的代价要认**：多数纯文生图**没有参考图槽**，出图端锁不住脸。所以：

- 一个角色**只出一次**三视图，出了就定版，全片不再重出
- 同一个角色**固定 seed**，中途要重出也只改 seed 不换 prompt 骨架
- 真正的锁脸在 H3 端做——那张三视图就是参考图槽，全片一直挂着

> 反过来：如果你的工具带参考图槽（换装/改脸），**不要用它来出三视图**——参考槽会把三视图三格之间的身份互相拽，
> 出成"三个差不多但不一样的人"。要换装就换 prompt 里的服装描述。

### 2.5 资产清单（Skill 产出，字段通用）

```json
[
  { "slot": "1", "role": "character", "name": "顾深", "seed": "184372",
    "aspect": "4:3", "megapixels": 2.0,
    "prompt": "三格横向并置，同一人物同一服装同一光位：正面全身 / 侧面全身 / 背面全身。28岁东亚男性，短寸黑发，左眉尾一道浅疤……" },

  { "slot": "6", "role": "scene", "name": "凶宅客厅", "megapixels": 2.0,
    "prompt": "民国凶宅客厅，正中一张深色八仙桌，两把高背玫瑰木椅相对……" },

  { "slot": "9", "role": "prop", "name": "冥币", "megapixels": 1.0, "aspect": "1:1",
    "prompt": "一叠民国冥币，黄纸朱印，边缘毛糙……" }
]
```

| 字段 | 说明 |
|---|---|
| `slot` | **图槽序号**，直接决定落盘文件名，也决定 `<Picture N>` 的编号 |
| `role` | `character` / `scene` / `prop`，只用来挑默认画幅和做三视图检查 |
| `name` | 中文短名，不超过 12 字 |
| `seed` | 角色必给；场景给了可复现，道具可省 |
| `aspect` / `megapixels` | 省略按 role 走默认（见下表）；字段名跟着你那套出图接口写 |
| `prompt` | 见 §二 的三个模板 |

**画幅与像素默认值**

| role | aspect | 像素 |
|---|---|---|
| character | `4:3` | 2.0（三格并排，横版才站得开） |
| scene | **`9:16`（推荐）/ `16:9`（横屏项目）——跟成片一致** | 2.0 |
| prop | `1:1` | 1.0 |

### 2.6 落盘命名与目录（硬规矩）

```
素材库/人物/{槽位号}_{名称}.png     例：人物/1_顾深.png
素材库/场景/{槽位号}_{名称}.png     例：场景/6_凶宅客厅.png
素材库/道具/{槽位号}_{名称}.png     例：道具/9_冥币.png
```

**图按类分开放**：人物 / 场景 / 道具。认不出的一律进 `其他`，不要混进人物里。
一集一套资产时再降一级：`人物/第02集/`。

命名只认**槽位号**——它是唯一和 `<Picture N>` 对得上的东西。

槽位号**两位对齐不补零也行，但必须与 `<Picture N>` 完全一致**。
视频清单里的 `images` 数组按槽位顺序排，第 N 个就是 `<Picture N>`。**命名错了整段白跑。**

### 2.7 出图流程（手工，三句话）

1. 按 §二 模板填 prompt（角色三视图 / 场景主视角 / 道具设定图），画幅按上表；
2. 一个角色出一个 seed，出到满意即定版，**记下 seed** 写回资产清单；
3. 按 §2.6 直接用**槽位号**命名落盘——不要在事后改名对号，那是错位的主要来源。

## 三、9 图预算表（Ref2VA 核心）

角色资产全量投喂会**瞬间超限**（3View × N 人 + 场景 + 道具 ≫ 9）。按优先级取：

| 优先级 | 取材 | 张数 |
|---|---|---|
| ① | **具体帧锚图**：首帧 / 尾帧 / 构图锚 | 1–2 |
| ② | **主要角色 3View**（每人 1 张板） | 主角 1 + 配角 1–2 |
| ③ | **核心场景**：一张主视角母版（就一张，不出九宫格） | 1 |
| ④ | 对手 / 次要角色 | 1–2 |
| ⑤ | 道具 | 多件**拼一板**算 1 张 |
| ⑥ | 动作/运镜参考视频 | ≤3 段 |
| ⑦ | 音色/BGM 音频 | ≤3 段（必须挂图或视频） |

**典型 15s 双人段 = 3–4 张**
```
图1 主角 3View · 图2 对手 3View · 图3 书房主视角 · 图7 道具（拼板）
= 4 / 9
```

**超限处置**：保 ①②③，其余降级为**文字档**写进 `<Subject N>` 定义行——**不丢信息，只丢"图锁定"强度**。

**铁律**：给了图却在正文一次没提到的 Subject = 白占额度（机检 H5 会抓）。**要么用，要么别投。**

## 四、参考图用途必须标注

每张图在定义行里写清它锁什么：

| 用途 | 写法 |
|---|---|
| 锁形象 | `<Subject 1> is the young woman in Picture 1: …` |
| 锁空间 | `<Subject 3> is the study in Picture 3: a dark wooden desk at the centre, …` |
| 锁道具 | `<Subject 4> is the handkerchief in Picture 4: off-white cotton, …` |
| 锁构图/帧 | `<Picture 2> aligns with the 8.00-second mark; …` |

## 五、M1 / M2 两档交付

### M1（默认，无图也能走）

产出：
1. 三清单（图号 + 一段可见描述）
2. 生图提示词（可直接粘到任何生图工具）
3. **9 图预算表**
4. 《素材接线单》：图号 → 对应 `<Subject N>` → 用途

下游分镜**照常写**，正文用文字档兜住外观（`<Subject 1> is the young woman with black shoulder-length hair, pale skin, a grey linen shirt`）。

**不许因为没图停工**，也不许反过来向用户索图后卡住。

### M2（有图，升级锁）

用户回传图后：
1. 逐张核对是否与三清单一致（不一致以**图**为准，回改清单）
2. 图号 → `<Picture N>` 映射，用途标注
3. 重排 9 图预算
4. 正文里补 `<Picture N>` 引用

## 六、角色一致性三条保命规则

1. **一段至少提一次**：每个在场角色，在 `detailed_description` 里至少被点名一次（H3 会按提到的人渲染，没提到的不生成）
2. **外观只写一次**：定义行写全，正文里只写"她/他"或一个短标记（`the woman in grey`），**不要每镜重复全套外观**——重复会把"描述"当"变化"渲染
3. **服装变化要显式说**：换装必须写"她换上了…"，否则 H3 会按参考图那套给你，或者给你两套混搭

---

## 七、人群调度（群戏别失控）

- **具名上限**：一个 15s 段里**有名字/有外观描述的**角色 ≤3 人
- 第 4 人起必须是"背景人"，写法：`three servants in grey stand along the wall, still`（数量 + 位置 + 状态，不给个体特征）
- **禁**："远处站着个人"（H3 会给你一个模糊鬼影或直接删掉）
- 群戏镜用**全景**交代人数，再用**中近景**给主焦点——不要在中近景里塞五个人
