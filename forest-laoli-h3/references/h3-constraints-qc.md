# H3 硬约束与机检全表（H1–H36）

> 每条约束都对应一个**真机实测崩法**。不是理论，是踩过的坑。

---

## 一、硬约束逐条（C1–C20）

1. **C1 时长 4–15 秒**：与载荷 `duration_seconds` 严格一致；不支持超过 15s 的单段。
2. **C2 参考素材上限（Ref2VA）**：图像 **≤9 张**；视频 ≤3 段（总 ≤15s）；音频 ≤3 段（必须与图或视频同用）；混合总数 **≤12 个**。**全片图槽顺序一次钉死，每段全挂不省图**。
3. **C3 画幅全片一致，推荐 9:16、16:9 可用**：载荷 `aspect_ratio`（或渲染端的 `ratio`）写 `"9:16"` 或 `"16:9"`，**禁 `auto` / `adaptive`**，禁段间换画幅。画幅不进正文。
4. **C4 正文全英文**：六段正文一律英文；只有 `<d>[Chinese] …</d>` 内台词与双引号内画内文字保留中文。
5. **C5 正文只写"有什么"**：禁否定式、禁 `@` 锚点、禁【】栏名、禁工作流规则词、禁坐标与 ASCII 框图。
6. **C6 保留度标记固定英文值**：画面 `fully_preserved / partially_preserved / attribute_transfer / weak_reference`；音频 `fully_copy / partially_copy / reference / weak_reference`；`retention_analysis` 禁写 `(Sx)`。
7. **C7 说话人编号与画外声**：`(Sx)` 按首现或全局槽位绑定；画外声必用 `<Subject N> (Sx) says in an off-screen voiceover: <d>[Chinese] …</d> while his/her lips remain completely closed.`（门外不入画角色只写 `the woman outside (S1)`，禁写 `<Subject N>`）。
8. **C8 任务类型前缀**：`reference generation` / `keyframe completion` / `video continuation` / `video editing` / `audio reuse` / `audio reference`。
9. **C9 单镜词数预算**：按镜算不按段算，单镜 **45–70 词**为健康区间（<35 词交代过薄 WARN，>75 词 WARN，**>100 词 FAIL 先丢机位**）。
10. **C10 语气位与声学反差**：发言人首次出场必给足音高/音质/语速；同段同性别 ≥2 个开口者时必须**声学反差拉满**（一低冷慢、一高亮快），否则必串音（issue #17）。
11. **C11 道具物理接地**：道具首现必写支撑面（`standing on the table` / `in her right hand`），禁只写相对位置。
12. **C12 空间锚点卡 + 维持句 + 末镜定格**：每段开头复述同一张单数家具锚点卡（禁 `wall of / rows of`）；每镜末尾加正向维持句；末镜加 1 秒定格句。
13. **C13 禁穿门融化（H29）**：人物绝不穿过门洞/窗洞/有框开口（`steps out through the door` 会被渲染成半透明 alpha 融化）。
14. **C14 同框人数与旁观锁（H30）**：一镜最多 2 个人物标签，第二人只写 `stands still`，禁写 `watches him go` 等旁观动态词。
15. **C15 门窗开闭状态锁 + 画外声源动作隔离（H31）**：
    - 门外敲门（`knocks`）等画外动作严禁写进画面正文（否则门内主角自己转身敲门），画面只写门震动/铁链响，敲门声进 `overall_soundscape`；
    - 未开门段与开门前镜头显式写 `the closed door stays shut`；段末有开门变化时，场景 `<Subject>` 标 `partially_preserved` 且不把门死锁在 `stay in place for every shot`（防分裂成“双扇门”）。
16. **C16 段内角色依托物唯一锁（H32）**：同段内无显式走位时，同一角色的固定依托物与左右位置严禁跳变（防左右同时画出两个主角分身）。
17. **C17 高危物理死锁禁区（H33）**：禁「全蹲 `crouches on his heels` + 低机位」与「薄物穿过极窄门缝动态过程 `slides through the gap`」（防卡死 76% 与成片冻帧 1.7s）。

## 二、机检全表（H1–H36 · `python scripts/h3_lint.py <稿> --duration 15`）

> 支持单段稿与多段合稿自动识别切分（默认按段切分 + 跨段图槽一致性 H34；传 `--whole` 强制按单段校验）。

| 门 | 检查什么 | 级别 | 崩了会怎样 |
|---|---|---|---|
| **H1** | 字段集完整；Ref2VA 六段顺序正确 | FAIL | 模型按错误顺序解析，字段被当正文 |
| **H2** | `[Shot 1]` 无时间戳；切点递增 < 时长；切镜动词合规 | FAIL | 时间轴错乱、出现叠化融脸 |
| **H3** | 时长 4–15s 且与载荷一致 | FAIL | 截断或补帧，末尾动作断裂 |
| **H4** | 正文英文（`<d>` 与引号内除外）；`<d>` 有语言标签 | FAIL/WARN | 切点/说话人/字幕执行率下降 |
| **H5** | 标签先定义后引用；定义 ≤9；定义了必须被引用 | FAIL/WARN | 白占额度；人物凭空消失 |
| **H6** | 保留度取合法英文值；`retention_analysis` 不含 `(Sx)` | FAIL | 解析失败或保留度被忽略 |
| **H7** | `(Sx)` 按首现顺序编号；未发声者无 ID | WARN | 声音绑错人 |
| **H8** | 栏名【】/`@`/ASCII/坐标 → FAIL；工程词/说明书 → WARN | FAIL/WARN | 栏名与框线被画进画面 |
| **H9** | 画外声含 `says in an off-screen voiceover` + 闭口证据紧跟 `</d>` | FAIL/WARN | 画外声角色照样张嘴 |
| **H10** | `overall_soundscape` 不含台词；BGM 只在 `non_diegetic_music` | FAIL/WARN | 声音通道混流，台词被念两遍 |
| **H11** | 说话人首现处有语气/音色/语速 | WARN | 语气丢失，全段一个调 |
| **H12** | 首镜有具名主体；无并列主体；无悬空代词 | WARN | 首镜空镜、手脸被渲染成两张脸 |
| **H13** | **词根清洗**：剥除 `<d>` 后扫否定/元描述/声音硬根 → FAIL；软根 → WARN | **FAIL/WARN** | 否定词被丢弃后词根被画出 |
| **H14** | **画幅全片一致**：`auto`/`adaptive` 或段间混用 → FAIL；单个非推荐比例（非 9:16 / 16:9）→ WARN；完全未声明 → WARN | FAIL/WARN | 段间画幅跳变，段缝崩 |
| **H15** | **运镜位移量与时长**：推拉必带 cm 级距离与时长 | WARN | 推镜过猛把人脸推变形 |
| **H16** | **禁用运镜**：升格 / slow motion / Hit-Stop / 滑动变焦 / 摇臂 → FAIL | FAIL/WARN | H3 做不出来，直接静帧或糊片 |
| **H17** | **运镜×景别矛盾**：特写配横移/跟拍/环绕 | WARN | 主体被甩出画面 |
| **H18** | **相邻两镜同运镜 / 连续静止** | WARN | 运镜单调或画面死板 |
| **H19** | **位移与变焦同镜叠加** | WARN | 疑似无声明滑动变焦，画面卡死 |
| **H20** | **台词密度**：填充率 <65% 或 >98%、空镜无人开口 | WARN | 观众体感没人说话或节奏过赶 |
| **H21** | **回合制切镜**：同一说话人相邻两镜连说（站桩） | WARN | 站桩式对话，缺正反打张力 |
| **H22** | **道具物理接地**：首现未写支撑面 | WARN | 火锅/杯子/手机悬浮半空 |
| **H23** | **镜行词数上限**：>75 词 WARN；**>100 词 FAIL** | **FAIL/WARN** | 指令超载，先丢机位再丢后半动作 |
| **H24** | **关键镜行维持句**：含家具/门窗镜行缺 `stay unchanged / stays shut` | WARN | 家具乱造、门窗自开、站位漂移 |
| **H25** | **单镜交代过薄**：单镜 <35 词 | WARN | 人物/位置/动作三缺一 |
| **H26** | **同性别多说话人**：同段 ≥2 个同性别开口者且无声学对比 | WARN | 官方 issue #17，男女/同性声音互串 |
| **H27** | **末镜定格句**：末镜缺 `movement stops / holds still` | WARN | 尾帧截不出，跨段接缝跳 |
| **H28** | **空间尺度膨胀**：出现 `wall of / rows of / dozens of` 复数扩建词 | WARN | 一面墙变百张照片展厅，房间翻倍 |
| **H29** | **消除式穿门动作**：人物穿过门洞/窗洞/开口（`steps out through the door`） | WARN | 人越过门框线即半透明 alpha 融化（段01 真机） |
| **H30** | **同框人数与身形复制**：同镜同标签多次引用、>2 人、双人加 `watches him go` | WARN | 同一人被画成两个半身（段01 真机） |
| **H31** | **门窗状态锁 & 画外敲门污染**：① 正文写 `knocks landing on the far side`；② 开门段死锁闭合门且标 `fully_preserved` | WARN | ① 屋里男主自己转身敲门（段02 真机）；② 单扇门分裂成左右两扇门（段04 真机） |
| **H32** | **段内角色依托物跳变**：同段无走位却更换角色依托物（抢占他人固定物） | WARN | 旧位与新位同时画出两个主角分身（段01 真机） |
| **H33** | **高危物理死锁动作**：全蹲 `crouches on his heels` / 窄缝穿物 `slides through the gap` | WARN | 生成卡死 76% 或成片冻帧 1.7s（段03 真机） |
| **H34** | **跨段图槽一致性**（多段合稿自动触发）：同一 `Picture N` 跨段人/景类型错位 | **FAIL** | 省图或贴错素材导致跨段换脸/人变房子 |
| **H35** | **氛围层缺失**：光位（光源+方向）/ 空气介质（烟尘雾汽）/ 前景景深，三类缺两类以上 | WARN | 平光片、有物件没空气、国漫 3D 塑料感（《暖阁》段01 缺 3/3） |
| **H36** | **图槽越界**（载荷 JSON 带 `images` 数组时触发）：正文最大 `Picture N` > 数组长度，或槽位为空值 | **FAIL** | 省图/漏传 → 后续槽位整体前移 → 人景贴反、卡死（见 `delivery.md §三`） |
